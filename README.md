# 明法众联

面向个人、机构与管理员三层身份分区的数智化法治实践平台。

## 在线演示

[打开 GitHub Pages 演示](https://xzfnx.github.io/mingfa-zhonglian/)

## 本地启动

```bash
npm install
npm run dev
```
